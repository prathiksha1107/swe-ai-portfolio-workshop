# Completed Minimal Professional Example

This folder preserves the completed personalized portfolio that was used to test and
finalize Template 1.

- `index.html` contains the personalized public site.
- `PROFILE.md` preserves the approved structured source used to generate it.
- `style.css` imports the stable Template 1 design.
- The page uses Template 1's shared `script.js` through a relative path.

Double-click `index.html` to preview the example. Personal contact information in
this folder belongs to the example owner and must not be copied into a participant's
starter profile.
