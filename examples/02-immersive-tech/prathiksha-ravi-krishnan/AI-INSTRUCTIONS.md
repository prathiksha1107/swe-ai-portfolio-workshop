# Instructions for Personalizing Immersive Tech

1. Read all of `PROFILE.md` before editing website files.
2. Continue only when it contains `Status: APPROVED FOR PORTFOLIO GENERATION`.
3. Use `PROFILE.md` as the only factual source. Never invent career facts, links,
   projects, technologies, outcomes, or metrics.
4. Preserve the immersive design system, visual hierarchy, CSS depth effects,
   canvas atmosphere, timeline, project-card conventions, and interaction model.
5. Preserve semantic HTML, heading order, keyboard navigation, focus styles, ARIA,
   contrast, skip navigation, reduced-motion behavior, and responsive behavior.
6. Do not remove animation merely because it is complex. Modify it only when needed
   to support personalized content or accessibility.
7. Do not increase animation intensity unless the participant specifically asks.
8. Remove empty sections and controls rather than inventing content. Remove matching
   navigation items when a section is removed.
9. Render the optional impact metrics section only when `PROFILE.md` contains
   explicitly verified numerical impact. Keep accessible static text even when a
   counter effect is used.
10. Render only approved email, LinkedIn, GitHub, and location information. This
    template intentionally has no contact form or WhatsApp control.
11. Keep a Resume control only when the approved profile requests it and
    `assets/resume.pdf` actually exists.
12. Keep all paths relative and preserve static GitHub Pages compatibility. Do not
    add frameworks, libraries, APIs, dependencies, or build tools.
13. Check every remaining link and asset reference.

## Project format

Keep each project's supported Problem, Approach, Impact, Technologies, GitHub, and
Live Demo fields. Omit a link when its approved URL is blank.

## Final placeholder audit

Search the complete template for starter names, example organizations, fictional
projects, `example.com`, empty links, placeholder URLs, missing assets, and unresolved
`[NEEDS CLARIFICATION]` markers. Replace content only when the approved profile
supports it; otherwise remove the element or section.
