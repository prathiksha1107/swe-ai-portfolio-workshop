# Prathiksha Ravi Krishnan — Chibi 3D Story

This is the completed, personalized example for Template 4. It preserves the
approved profile, portfolio content, character model, animations, contact form,
and participant-owned Microsoft Clarity configuration.

The reusable starter is located at:

```text
templates/04-chibi-3d-story/
```

## Run this example

```powershell
npm.cmd install
npm.cmd run dev
```

Open the local URL printed by Vite. Use `npm.cmd run build` to verify the production
site. Do not copy this example's personal information, character, contact endpoint,
or analytics ID into a participant portfolio.
